# Questão 01:

# A) População = Todos os 10.000 usuários cadastrados.
# População é o conjunto de elementos (não necessáriamente humanos) que serão analisados, geralmente possui um grande número de elementos (dados).

# B) Amotra = Os 500 candidados selecionados aleatóriamente.
# Amostra é uma parte da população separada para análise, por ser uma parte possui um tamanho menor que a população. A amostra deve ser uma representação fiel da população.

# C) Unidade Estátisca = Um usuário.
# A Unidade estátistica é um elemento individual que está sendo analisado.
